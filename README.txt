SCOOP MANAGER — PWA PACKAGE
============================

Upload ALL files in this folder to the SAME directory on GitHub Pages.

Required files:
  index.html
  manifest.json
  service-worker.js
  favicon.ico
  favicon-32.png
  apple-touch-icon.png
  icon-192.png
  icon-512.png
  icon-maskable-192.png
  icon-maskable-512.png

The ice-cream logo is used ONLY for:
  - Browser tab favicon
  - Home-screen / installed app icon
  - PWA install prompt

Inside the app, the original UI (yellow logo-dot + text) is unchanged.

After upload:
  1. Open the HTTPS GitHub Pages URL in Chrome
  2. Hard-refresh (Ctrl+Shift+R)
  3. Tap "Install App" (or use the browser install icon)

If an old Scoop Manager shortcut already exists, remove it first.
